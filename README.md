# **Stone Paper Scissors Game**

A simple, interactive Stone Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer, track your scores, and enjoy a clean and user-friendly interface.

🚀 **Live Demo**

Play Stone Paper Scissors

🛠️ **Technologies Used**

HTML5 – Structure of the game.

CSS3 – Styling and user interface.

JavaScript – Game logic, computer moves, result calculation, and score tracking.

🎮 **Features**

Play against the computer.

Random computer move generation.

Automatic winner detection.

Real-time score tracking (Wins, Losses, and Draws).

Reset Score functionality.

Interactive buttons with visual icons.
